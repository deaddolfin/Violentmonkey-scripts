# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Userscript **Gallery Scroll View** для Violentmonkey/Tampermonkey (версия `1.0.13`).
Заменяет постраничный reader галерей на непрерывную вертикальную ленту («свиток») с зумом,
автопрокруткой, управлением с клавиатуры и плавающей панелью.
Поддерживаются imhentai.xxx / hentaiera.com / hentaienvy.com и hitomi.la.

Разработка ведётся на **Windows 11** — для терминальных команд использовать синтаксис PowerShell.

> Текущее состояние работы и следующие шаги — в **`STATUS.md`** (читать первым при старте сессии).
> Границы работы агентов — в **`AGENTS.md`**.

## Команды

Сборки нет — скрипт представляет собой один самодостаточный файл без зависимостей.

- `node --check gallery-scroll-view.user.js` — проверка синтаксиса (единственная автоматическая проверка).
- Тестов нет. Функциональная проверка — только вручную: установить файл в Violentmonkey
  (перетащить в браузер) и открыть reader-страницу поддерживаемого сайта.
- Публикация: залить файл в gist (`@downloadURL` / `@updateURL` в шапке), затем форс-обновить
  скрипт в Violentmonkey. **Без поднятия `@version` обновление не подтянется.**

## Архитектура

Весь код — одна IIFE в `gallery-scroll-view.user.js` (~1090 строк), разбитая комментариями-секциями:

1. **Настройки** (строки ~23–40) — константы: `IMAGES_BEFORE/AFTER` (стартовое окно ±10),
   `TOP_OFFSET` (56px, высота верхней панели — используется для якорной прокрутки),
   `WIDTH_OPTIONS`, границы `Speed`, `SCROLL_SPEED_FACTOR` (единый множитель px/кадр —
   держит скорость кнопок и автоскролла одинаковой), `EXT_MAP` (код расширения в `g_th`).
2. **Состояние панели** (`loadState`/`saveState`) — `localStorage`, ключ `gsv-panel-state`:
   позиция панели, свёрнута/скрыта, `speed`, `zoom`.
3. **Разбор reader-страницы** — `getReaderImage`, `parseImageSrc`, `parseGth`, `getTotalPages`,
   `dimsForPage`, `extForPage`.
4. **Адаптеры** — `imhentaiAdapter`, `hitomiAdapter`, выбор через `getAdapter()` по `hostname`.
5. **Оверлей** — `openScrollView(context)` / `closeScrollView()`: верхняя панель, контейнер строк,
   плавающая панель, drag-скролл, клавиатура, бесконечная лента.
6. **Плавающая кнопка** — `addFloatButton()` + `init()` с ретраями (данные могут догружаться).

### Контракт адаптера

Адаптер обязан реализовать:

```js
{
  ready(),                    // данные страницы уже доступны?
  getContext() -> {
    total,                    // всего страниц
    current,                  // текущая страница
    makeItem(n) -> {          // данные одной страницы ПО ТРЕБОВАНИЮ (или null)
      page, url,
      width, height,          // реальные размеры — для резервирования высоты строки
      allowExtFallback?,      // разрешён перебор расширений при ошибке загрузки
      referrerPolicy?,        // 'no-referrer' для CDN imhentai
    }
  }
}
```

Ленивость `makeItem` — ключевая: именно она позволяет ленте расти при прокрутке,
а не строиться фиксированным окном. Новый сайт добавляется как ещё один адаптер +
`@match` в шапке + ветка в `getAdapter()`.

**imhentai-семейство**: базовый CDN-путь берётся из `src` текущей картинки
(`#gimg` / `#fimg` / `img[class*="image_"]`), URL страницы N собирается как `base + N + '.' + ext`.
Расширение и размеры — из словаря `g_th` (`{"1":"j,560,420", …}`, первый символ = код расширения),
который парсится регуляркой из инлайн-`<script>`. Текущая страница — из URL `/view/{id}/{page}/`.

**hitomi.la**: переиспользуются функции самой страницы — `window.galleryinfo.files` и
`window.make_image_element(id, file)` (из него берётся `<img>.src`). Это устойчиво к ротации `gg.js`
и требует, чтобы скрипт выполнялся **в контексте страницы** — отсюда **`@grant none`**.
Менять `@grant` нельзя, иначе адаптер hitomi перестанет видеть `window.galleryinfo`.
Текущая страница — из `location.hash` (`#5`).

### Инварианты, которые легко сломать

- **Резервирование высоты.** Каждая строка получает `aspect-ratio` из реальных размеров.
  Без этого при ленивой загрузке высота меняется на лету, скролл «прыгает», а переходы
  промахиваются на несколько страниц.
- **Компенсация scrollTop.** `prependPrev()` и верхняя ветка `trimFar()` добавляют/удаляют
  контент *над* вьюпортом и обязаны корректировать `overlay.scrollTop` на разницу `scrollHeight`.
- **`SCROLL_SPEED_FACTOR` общий** для удержания кнопок/стрелок и автопрокрутки — при одном
  значении `Speed` скорость должна совпадать.
- **Смена `Width` сбрасывает `Zoom` в 0** (`Zoom` — аддитивная прибавка в %, а не множитель).
- **Снятие обработчиков.** `closeScrollView()` обязан снимать `keydown`/`keyup` с `document`,
  останавливать таймеры (`stopHold`, `stopAuto`) и возвращать `document.body.style.overflow`.
- **Клавиши не перехватываются**, когда фокус на `INPUT`/`SELECT`/`TEXTAREA` или зажат
  Ctrl/Alt/Meta; неизвестная клавиша уходит странице (`default: return` до `preventDefault`).

### Бесконечная лента

`onScrollExtend` (слушатель `scroll` оверлея, защищён флагом `extending`):

- ближе `EXTEND_THRESHOLD` (1200px) к краю — `prependPrev()` / `appendNext()` партиями по `EXTEND_BATCH` (6);
- `trimFar(anchor)` удаляет строки дальше `KEEP_MARGIN` (50) страниц от видимой;
- `dominantInfo()` считает страницу с максимальной видимой высотой (дёшево: `offsetTop`/`offsetHeight`,
  ранний `break` ниже вьюпорта); номер в счётчике меняется при `fraction >= SWITCH_FRACTION` (0.7)
  либо когда текущая страница вообще не видна.

Слушатель `scroll` вешается **после** стартового позиционирования (двойной `requestAnimationFrame`),
чтобы начальный `scrollTop` не вызвал лишнюю догрузку.

### Загрузка изображений

`createRow` → `el.onerror`: (1) перебор `jpg/png/webp/gif`, если `allowExtFallback`;
(2) до 2 повторов того же URL с задержкой `350 * retries` (сетевые сбои / троттлинг CDN);
(3) плейсхолдер с кнопкой `↻ Повторить`. Картинки грузятся `loading="eager"` намеренно —
при быстрой прокрутке ленивая загрузка оставляла «дырки».

## Связанные проекты

Скрипт вырос из Stash-плагина **GalleryScrollView**
(`F:\soft\stash_docker\data\plugins\MyPlugins\GalleryScrollView`) — там та же идея свитка,
но источник картинок — GraphQL Stash, а UI встроен в Stash. Это **отдельный проект**;
код разошёлся (здесь адаптеры сайтов, бесконечная лента, клавиатура — там переход по номеру
страницы и `PluginApi`). Изменения между ними не синхронизируются автоматически, и трогать
каталог плагина из этого проекта нельзя (см. `AGENTS.md`).
