## Открытые вопросы

- **Дублирование с Stash-плагином.** `GalleryScrollView.js` в каталоге плагина решает ту же
  задачу для Stash. Код разошёлся; общей библиотеки нет и синхронизация ручная.
  Вопрос объединения не поднимался — пока это два независимых проекта.
- **Ротация CDN.** Для imhentai базовый путь берётся из `src` текущей картинки, расширения —
  из `g_th`. Если сайт сменит разметку (`#gimg`/`#fimg`, формат `g_th`) или схему URL,
  адаптер придётся править. Для hitomi риск ниже — используются функции самой страницы.
- **`@grant none` обязателен** (адаптер hitomi читает `window.galleryinfo`). Если когда-нибудь
  понадобится `GM_*` API, hitomi нужно будет переписывать.
- Публикация: `@downloadURL`/`@updateURL` указывают на raw-ссылку ветки `main` без хэша
  коммита. Доступность зеркала проверена 2026-09-07 (raw отдаёт 200, дефолтная ветка `main`).
  Старый gist `fa59bf3e3bc465e70960e237491fe43f` больше не источник истины — решить,
  удалять его или оставить заглушкой со ссылкой на репозиторий.
