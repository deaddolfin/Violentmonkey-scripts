# Agents Workspace Configuration

## Рабочий каталог

`F:\MyProject\Violentmonkey\gallery-scroll-view`

## Ограничения

- Агентам разрешено работать только в этом каталоге и его подкаталогах.
- Запрещено изменять файлы за его пределами без явного одобрения пользователя.
  В частности — не трогать исходный Stash-плагин
  `F:\soft\stash_docker\data\plugins\MyPlugins\GalleryScrollView` (это отдельный проект,
  см. «Связанные проекты» в `CLAUDE.md`).
- Все новые файлы и изменения должны создаваться в этом каталоге.

## Платформа

Windows 11. Для терминальных команд использовать синтаксис PowerShell
(`Get-ChildItem`, `Copy-Item`, `$env:VAR`), не bash.

## Правила работы с кодом

- Скрипт — один файл `gallery-scroll-view.user.js`, без сборки, без зависимостей.
  Не вводить бандлер/npm без запроса пользователя.
- При изменении поведения поднимать `@version` в шапке `==UserScript==` —
  иначе Violentmonkey не подтянет обновление из репозитория.
- Комментарии в коде — на русском, в существующем стиле (секции `// ─── … ───`).
  Объяснять *почему*, а не *что*.
- Проверка синтаксиса перед сдачей: `node --check gallery-scroll-view.user.js`.
  Автотестов нет — функциональная проверка только вручную в браузере.
- Не добавлять `@grant`, кроме `none`: адаптер hitomi.la зависит от выполнения
  скрипта в контексте страницы (см. `CLAUDE.md`).

## Документация

- `STATUS.md` — обновлять при завершении сессии: где остановились, что открыто.
- `README.md` — обновлять при изменении UI, горячих клавиш или списка сайтов.
- `CLAUDE.md` — обновлять при изменении архитектуры или инвариантов.
