# Gallery Scroll View

Userscript для **Violentmonkey / Tampermonkey**: свиток-просмотр галерей на
imhentai-подобных сайтах и hitomi.la. Вместо постраничного reader'а —
непрерывная вертикальная лента с зумом, автопрокруткой и управлением с клавиатуры.

Версия: **1.0.13** · автор: DeadDolfin · `@grant none`

## Поддерживаемые сайты

| Сайт | Совпадение `@match` | Адаптер |
|---|---|---|
| imhentai.xxx | `https://imhentai.xxx/view/*` | `imhentaiAdapter` |
| hentaiera.com | `https://hentaiera.com/view/*` | `imhentaiAdapter` |
| hentaienvy.com | `https://hentaienvy.com/g/*` | `imhentaiAdapter` |
| hitomi.la | `https://hitomi.la/reader/*` | `hitomiAdapter` |

## Установка

1. Установить Violentmonkey (или Tampermonkey) в браузер.
2. Открыть `gallery-scroll-view.user.js` — либо перетащить файл в окно браузера,
   либо в панели Violentmonkey: *Установить из URL* с ссылкой на gist
   (`@downloadURL` в шапке скрипта).
3. Подтвердить установку. Обновления берутся из gist по `@updateURL`.

Ссылка на gist: <https://gist.github.com/deaddolfin/fa59bf3e3bc465e70960e237491fe43f>

## Использование

1. Открыть страницу чтения галереи на поддерживаемом сайте.
2. Нажать плавающую кнопку **📜** в правом нижнем углу.
3. Откроется оверлей: лента стартует с текущей страницы (±10 страниц вокруг),
   дальше подгружается сама при прокрутке.
4. Выход — кнопка **✕ Закрыть** или `Esc`.

### Верхняя панель

- Счётчик `Страница N / всего` — номер обновляется, когда новая страница заняла
  больше 70 % видимой области.
- `Width` — базовая ширина ленты: 100 % / 90 % / 75 % / 60 % / 1200px / 900px / 600px.
  Смена ширины сбрасывает `Zoom` в 0.
- `◫ Панель` — показать/скрыть плавающую панель.
- `✕ Закрыть`.

### Плавающая панель «Свиток»

- `Zoom` (0–100) — прибавка к значению `Width`. Когда лента шире экрана,
  включается горизонтальная прокрутка (мышью/пальцем).
- `Speed` (0.30–2.20, шаг 0.05) — скорость прокрутки для кнопок и автоскролла.
- `↑` / `↓` — нажатие: шаг; удержание: непрерывная прокрутка со скоростью `Speed`.
- `▶` / `⏸` — автопрокрутка вниз.
- `−` в заголовке — свернуть/развернуть; заголовок можно перетаскивать.

### Клавиатура

| Клавиша | Действие |
|---|---|
| `↑` / `↓` | шаг прокрутки; при удержании — непрерывная со скоростью `Speed` |
| `←` / `→` | горизонтальная прокрутка (при зуме) |
| `PageUp` / `PageDown` | прокрутка на ~85 % экрана |
| `Home` / `End` | в начало / конец загруженной ленты |
| `+` / `−` | зум ±5 |
| `*` / `/` | скорость ±0.05 |
| `Пробел` | старт/пауза автопрокрутки |
| `Esc` | закрыть свиток |

Когда фокус в `input` / `select`, клавиши не перехватываются.

### Мышь и тач

- Перетаскивание — прокрутка ленты (вертикально и, при зуме, горизонтально).
- Щипок двумя пальцами — изменение `Zoom`.

## Что сохраняется

В `localStorage`, ключ `gsv-panel-state`: позиция панели, свёрнута/скрыта, `Speed`, `Zoom`.
Позиция панели восстанавливается, только если она попадает в текущее окно
(иначе панель вернётся к позиции по умолчанию).

## Особенности реализации

- **Бесконечная лента.** Стартовое окно ±10 страниц, догрузка партиями по 6 при
  подходе к краю (порог 1200 px), выгрузка строк дальше 50 страниц от видимой —
  DOM не растёт бесконечно.
- **Без «прыжков» скролла.** Высота каждой строки резервируется через `aspect-ratio`
  по реальным размерам изображения (у imhentai — из `g_th`, у hitomi — из `galleryinfo`).
  При добавлении страниц сверху `scrollTop` компенсируется.
- **Устойчивая загрузка.** При ошибке: перебор расширений (`jpg/png/webp/gif`, только
  imhentai) → 2 повтора с паузой → плейсхолдер с кнопкой `↻ Повторить`.
- **hitomi.la** использует собственные функции страницы (`window.galleryinfo`,
  `window.make_image_element`) — поэтому скрипт работает с `@grant none`
  (в контексте страницы) и не ломается при ротации `gg.js`.
