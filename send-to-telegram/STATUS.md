# STATUS — Send to Telegram

Обновлено: 2026-10-30
Версия скриптов: **1.0.0** (оба)

## Где остановились

Написаны оба варианта, синтаксис проверен (`node --check`). Реальная отправка **не проверена**:
нет токена бота. Доступность `api.telegram.org` с этой машины проверена `curl`-ом (ответ 404 JSON
на фиктивный токен за 0,4 с — API доступен).

## Что сделано

- Режим выбора картинки (подсветка, клик, `Esc`, `Alt+Shift+S`).
- Отправка ссылки страницы и выделенного текста.
- Вариант А: `sendPhoto` по URL → при неудаче `sendDocument` по URL.
- Вариант Б: то же + резерв «скачать через `GM_xmlhttpRequest` и загрузить `multipart`».
- Настройки через меню (токен, Chat ID, файл/фото, подпись с источником).
- В корне репозитория добавлены `.gitattributes` и gitleaks (`.gitleaks.toml`, `.githooks/`).

## Следующие шаги

1. Создать бота, поставить один из вариантов, проверить отправку: JPEG, WebP, картинку за авторизацией,
   `blob:`-картинку (только Б).
2. Проверить, что `GM_xmlhttpRequest` принимает `FormData` с `Blob` в установленной версии Violentmonkey (путь Б).
3. Решить, оставлять ли оба варианта или один.

## Открытые вопросы

- Исходная причина сбоя аддона неизвестна; Bot API с этой машины доступен.
- Картинки из CSS `background-image` режим выбора не видит — только `<img>`.
