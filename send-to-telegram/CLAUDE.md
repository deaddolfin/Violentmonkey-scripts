## Кратко

Два userscript (А — строгий, Б — с резервной загрузкой файла) для отправки в Telegram через Bot API.
Общий код продублирован в обоих файлах — правьте оба.

## Проверка

```powershell
node --check send-to-telegram.user.js
node --check send-to-telegram-fallback.user.js
```

## Окружение

- Windows 11, основная оболочка — PowerShell.
- Рабочая директория: `F:\MyProject\Violentmonkey\send-to-telegram`.

## Ловушки

- Не поднять `@version` после правки (в обоих файлах) = авто-обновление не сработает.
- Не менять `@downloadURL`/`@updateURL`; не добавлять `@connect *` в вариант А.
- Токен бота не логировать и не коммитить. Для проверки сети брать фиктивный токен:
  `curl https://api.telegram.org/bot000/getMe` отвечает 404 JSON — значит, API доступен.
- VPN на машине рвёт соединения после ~30 с тишины: долгие загрузки отсюда тестировать нельзя.
