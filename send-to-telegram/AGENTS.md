# AGENTS.md — правила работы с этим проектом

Общий свод для любых AI-агентов (Claude Code, Codex и др.). `CLAUDE.md` ссылается сюда.

## Что это за проект

Два userscript для Violentmonkey, шлющие в Telegram (Bot API) картинку, ссылку страницы или
выделенный текст. Описание для пользователя — `README.md`, состояние работ — `STATUS.md`.

## Структура

```
send-to-telegram.user.js            вариант А: только URL, @connect api.telegram.org
send-to-telegram-fallback.user.js   вариант Б: А + резерв «скачать и загрузить», @connect *
README.md / STATUS.md               документация и состояние
AGENTS.md / CLAUDE.md               правила для агентов
```

Файл Б — это файл А плюс блок «Путь Б» и другая `sendImage()`. **Общий код дублируется,
держите оба файла синхронными вручную**: правка в общей части (настройки, тосты, режим выбора,
`tgCall`) делается в обоих. Единственные отличия — шапка (`@name`, `@downloadURL`/`@updateURL`,
`@connect *`, `@description`) и блок между `sendImageByUrl` и `sendPickedImage`.

## Проверка изменений

```powershell
node --check send-to-telegram.user.js
node --check send-to-telegram-fallback.user.js
```

Остальное — вручную: установить в Violentmonkey, заполнить токен и Chat ID, отправить картинку
с публичного сайта. Агент реальную отправку не проверяет (нет токена) — пишите об этом пользователю.

## Соглашения по коду

- Vanilla JS, IIFE + `'use strict'`, без зависимостей и бандлеров; секции отделены баннерами `// ----...`.
- Комментарии на русском, о том *почему*, а не *что*. Классы CSS — префикс `vm-tg-`.
- Сеть — только `GM_xmlhttpRequest` (CORS). **Токен бота сидит в URL запроса: не логируйте URL
  и не кладите его в тексты ошибок.**
- `@connect` в варианте А — только `api.telegram.org`; не добавляйте `*` туда, это смысл варианта.
- Настройки: `token`, `chatId`, `asDocument`, `withSource` в `GM_setValue`. Секреты в репозиторий
  не класть; перед коммитом работает gitleaks-хук (`.githooks/` в корне репозитория).

## Версионирование и публикация

- Любая правка кода → поднять `@version` **в обоих файлах** (они обновляются независимо, но версии держим равными).
- `@downloadURL`/`@updateURL` — raw-ссылки ветки `main` без хэша коммита; не менять.
- Публикация = коммит и пуш в репозиторий (на GitHub уезжает зеркалом).
- Идентификатор скрипта в Violentmonkey — пара `@name` + `@namespace`; переименование = новая запись
  и потеря настроек.
