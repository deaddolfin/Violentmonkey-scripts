## Открытые баги (сообщены пользователем, не воспроизведены)

1. **«Нет настроек символов для новых состояний».** В исходниках поля есть
   (`src/settings/general.ts`: секция «Symbol» — `Show tag mark`, `Show no-file mark`, `Tag mark`,
   `No-file mark`; секция «Tags» — `Tag list (comma separated)`), и они присутствуют в собранном бандле.
2. **«Вместо `tagMark` применён символ check».** Сцена с тегом из списка показывает `✓` вместо `⚑`
   (state = `Check`, а не `Tag`). На капче `temp/html.html` tag-состояний нет (только check/cross) —
   сценарий не воспроизведён.

**Прежняя ведущая гипотеза («в браузере старая версия из gist») опровергнута** — 2026-08-16
сверено, что в gist лежал актуальный на тот момент бандл 1.3.0, байт в байт равный локальному
`dist`. Остаются другие причины, проверять их по порядку:

- в Violentmonkey установлена старая копия скрипта (ставилась из файла или из dev-сборки) —
  проверить `@version` именно в установленном скрипте;
- настройки в storage сохранены от прежней версии — при `Reset` в секции «Default Settings»
  подтягиваются дефолты новых ключей (`tagMark`, `noFileMark`, `showTagMark`, `showNoFileMark`);
- `tagList` фактически пуст или теги не совпадают: сравнение точное по имени, регистр не важен,
  пробелы обрезаются (`getSettingsTags` в `src/tooltip/tooltip.ts`);
- запись не доходит до ветки Tag из-за приоритета: при `data.length > 1` состояние всегда `Warning`,
  тег не проверяется (`resolveState`);
- у записи в ответе нет `tags`: `getDataFields` (`src/check.ts`) запрашивает их всегда, но для
  стеш-боксов (`stashdb.org` и т.п.) запрос идёт по `stash_id` в **ваш** Stash — теги берутся оттуда,
  а не со страницы StashDB.

## Открытые вопросы / решённое

- Рамка карточки агрегирует символы **того же target** (фильтр по `data-target`) — статус студии
  или исполнителя внутри карточки на рамку сцены не влияет. Приоритет цвета = приоритет состояний.
- Селектор страницы **отдельной сцены** StashDB — `.scene-info` — так и **не проверен** (капчи были
  списком/поиском). При другой вёрстке уточнить в `src/stashChecker.ts`.
- `cardSelector` задан только для iwara / javdb / стеш-боксов. Для остальных сайтов добавлять
  и проверять вручную (см. `AGENTS.md`).
