# STATUS — StashDB → Stash Scene Importer

Обновлено: 2026-08-16
Версия скрипта: **1.1.1** (локально и в gist — совпадают)

## Где остановились

Userscript готов и работоспособен, синтаксис проверен (`node --check` — чисто).
Реализован полный поток из ТЗ (`tz.txt`): кнопка на страницах `stashdb.org` →
получение сцены из StashBox (GraphQL) → создание сцены в локальном Stash (GraphQL).
Скрипт опубликован в gist, авто-обновление настроено.

Файл: `stashdb-to-stash.user.js`
Gist: https://gist.github.com/deaddolfin/11a719ab06fd3b5424e491ff45c56b87

## Что сделано

- Обнаружение ссылок `/scenes/<uuid>` в списках + кнопка «→ Stash» после ссылки.
- Одна кнопка на карточку сцены (`.SceneCard` / `.card`) — превью и заголовок больше
  не порождают дубли кнопок.
- Кнопка на самой странице сцены (после заголовка) с корректной заменой при
  SPA-навигации между сценами.
- Поток импорта: `findScene` (StashBox) → дедуп по `stash_id_endpoint` → сопоставление
  студии/актёров/тегов в Stash (найти-или-создать) → `sceneCreate`.
- Доп. теги из настроек (через запятую) подмешиваются к тегам сцены с дедупликацией
  по имени без учёта регистра.
- Настройки через меню Violentmonkey: URL+ApiKey StashBox и Stash, доп. теги.
- Метаданные авто-обновления: `@downloadURL`/`@updateURL` на raw gist без хэша.
- Заливка версии 1.1.1 в gist — **выполнено** (проверено 2026-08-16: в gist 1.1.1
  с update-ссылками).
- Документация: `README.md`, `AGENTS.md`, `CLAUDE.md` (2026-08-16).

## Следующие шаги (по приоритету)

1. **Проверка в бою на `stashdb.org`**: заполнить настройки (ApiKey StashBox из профиля,
   URL+ApiKey своего Stash), нажать кнопку на реальной сцене — в списке, в карточке
   и на странице сцены.
2. По итогам проверки уточнить селектор заголовка на странице сцены, если кнопка встала
   не туда (`scanScenePage()`).
3. Опционально: усилить сопоставление актёров/студий по `disambiguation`/`stash_id`,
   чтобы не привязывать тёзок.

## Открытые вопросы / отложенные решения

- **Селектор заголовка страницы сцены** подобран эвристикой (`main h1, main h3,
  .NarrowPage h3, h1` → `h1, h3`) — реальную разметку stashdb.org проверить не удалось
  (сайт требует авторизации). При необходимости поправить в `scanScenePage()`.
- Сопоставление студий/актёров/тегов идёт по **точному совпадению имени** (без учёта
  регистра). Возможны ложные привязки тёзок.
- `cover_image` передаётся как URL — Stash качает картинку сам; при отсутствии у инстанса
  доступа в интернет обложка не подтянется.
- Git в проекте не инициализирован: истории изменений нет, откат правок невозможен.

## Как запустить и проверить

- Синтаксис: `node --check stashdb-to-stash.user.js`
- Установка: дашборд Violentmonkey → установить из файла (или перетащить `.user.js`).
- Настроить через меню Violentmonkey → «⚙️ Настройки импорта в Stash».
