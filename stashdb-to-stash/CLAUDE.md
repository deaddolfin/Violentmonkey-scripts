## Кратко о проекте

Userscript для Violentmonkey: кнопка на `stashdb.org`, которая тянет сцену из StashBox
(GraphQL) и создаёт её в локальном Stash (GraphQL). Весь код — в одном файле
`stashdb-to-stash.user.js`, зависимостей и сборки нет.

## Проверка

```powershell
node --check stashdb-to-stash.user.js
```

Уже разрешено в `.claude/settings.local.json` — прогоняйте после каждой правки кода.
Тестов нет; поведение в браузере агент проверить не может, stashdb.org требует авторизации.

## Окружение

- Windows 11, основная оболочка — PowerShell. Bash-инструмент тоже доступен, но команды
  в примерах документации пишите в PowerShell-синтаксисе.
- Рабочая директория: `F:\MyProject\Violentmonkey\stashdb-to-stash`.
- Git не инициализирован — истории изменений нет, откатиться нельзя. Перед крупным
  рефакторингом единственного файла кладите копию в scratchpad.

## Ловушки

- Не поднять `@version` после правки = авто-обновление у пользователя не сработает.
- Не менять `@downloadURL`/`@updateURL` — raw-ссылка gist специально без хэша коммита.
- Не переписывать `gql()` на `fetch` — нужен `GM_xmlhttpRequest` ради обхода CORS.
- Селекторы DOM stashdb.org (`SCENE_RE`, `.SceneCard`, поиск заголовка в `scanScenePage()`)
  подобраны эвристически и не верифицированы на живом сайте — правки в них помечайте
  как требующие ручной проверки.
